# Tanzanian Customer Choice Predictor

A machine learning application that predicts customer satisfaction based on product attributes and customer demographics in the Tanzanian market.

## Features
- Predict customer satisfaction score (0-100%)
- Regional market analysis
- Factor importance visualization
- Product optimization suggestions

## How to Use
1. Enter customer demographics
2. Select product attributes
3. Adjust choice factors
4. Click "Predict" to see results
